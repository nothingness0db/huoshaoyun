## 4. 计算方法

### 4.1 鲜艳度指数（0.0 ~ 2.5，对数感刻度）

主页只显示数值+括号语义（如 `鲜艳度 0.0（不烧）`），完整分级藏在详情/地图页：

| 范围 | 语义 |
|---|---|
| 0.001~0.05 | 微微烧 / 云况不典型未预报出 |
| 0.05~0.2 | 小烧（大气很通透才好看） |
| 0.2~0.4 | 小烧到中等烧 |
| 0.4~0.6 | **中等烧——"比较值得看"的出门线** |
| 0.6~0.8 | 中到大烧 |
| 0.8~1.0 | 不完美大烧（云量不足/大气污/持续短/低云遮挡） |
| 1.0~1.5 | 典型大烧 |
| 1.5~2.0 | 优质大烧（范围广/云量大/颜色明亮/持续长/通透） |
| 2.0~2.5 | 世纪大烧（接近满云量、鲜艳、持续久、极通透） |

鲜艳度考虑因素：**持续时间、亮度与颜色、云量（格点云量、云相态与含水量）、占据天空面积、云底高度、层间照明与遮挡关系、AOD/雾**。
AOD 语义：0.0~0.1 水晶天（高原常见）｜0.1~0.2 普通水晶天｜0.2~0.3 非水晶蓝天｜0.3~0.4 普通｜0.4~0.6 有点污｜0.6~0.8 相当污（近地面有霾）｜>0.8 非常污（重霾）。

### 4.2 几何模型（教程第一章，可直接复刻的数学）

**火烧云三角**（核心结论）：
- 平底层状云火烧云只在日出前/日落后出现；云底越高范围越大；近云边界处持续最久；晚霞自云边界内侧向外扩展（朝霞相反）；云边界越远与本地日落时差越大；即使本地云边界不可见也可能出霞（边界较远）。
- 霞光深入距离（勾股定理）：云底 2/3/6/8km → 319/391/553/638km。近似式误差 <1km。
- **坐标变换**：以地球半径为参数做极坐标近似（直线→抛物线，旋转→平移），这是全套计算的基石。
- **高度角近似**：视线高度角公式（正弦定理展开至二次项），1000km 内误差 <2%。例：云边界 200km + 云底 9.2km → 高度角 1.74°。
- 对流云火烧云：云顶越高烧越久；云洞漏光：持续时间 ≤ 典型云况。
- **日落线速度**（附录表）：上海约 21km/分钟（教程案例深圳 17:47 日落、伊春 18km/分钟）——计算持续时间的核心参数。

**光谱消光**：
- 光学厚度 = 消光系数沿光路积分；能见度 V = 3.912/β(550nm)（光强降至 2%）。
- 瑞利散射 ∝ λ⁻⁴（滤蓝留红）；气溶胶米散射波长依赖弱（α≈1，0~2）；云滴 ~10μm 散射与波长无关（云显白）。
- 气溶胶消光随高度指数衰减。AOD<0.1 水晶天；0.5~0.8 明显损质；>0.8 污烧。
- 颜色规律：云底越高颜色越全（金黄→橘红→暗红），低云底仅橘红；云边界越远越红。
- **等效地表高度**（关键修正）：假设消光系数 ≥ 某阈值（经验值 0.02）时阳光无法穿透 → 大气层等效于抬升的地面。等效云底 = 真实云底 − 等效地表高度。AOD 高度衰减常数 0.5~4.0km 时等效地面高度 1.3~2.8km，对结论影响巨大（可能把"有晚霞"翻成"没有"）。

### 4.3 云属判据（教程第二三章）

| 云属 | 云底高度 | 火烧云价值 | 关键判据 |
|---|---|---|---|
| 层云 | <500m | 无（只做云海陪衬） | 贴地湿薄层 |
| 层积云 | 0.5~2.5km | 低；云底>2km 且大气极净才有短时橘红；主价值云隙光 | 冷流云/闭合细胞状云系 |
| 积云/积雨云 | 0.5km+ | 对流云/云砧晚霞 | 斜温图不稳定层越过 -20℃ 判积雨云；云砧晚霞常见于盛夏热对流消亡期 |
| 高层云 | >2.5km，厚>1km | **最壮观**（橘黄→红），可伴火烧云彩虹 | 系统性抬升；液态主导 vs 卷层云发展型 |
| 高积云 | 2.5~10km，厚数百米 | 壮观（橘黄→橘红），伴冰晕 | 云底<-20℃ 易落幡云洞，很少<-35℃ |
| 卷云 | >6km，厚 2~3km | 最常见，金→红，持续久 | 丝缕状；云底<-38℃ 必为卷云 |
| 卷层云 | >6km，厚 2~3km+ | 壮观度第二，面积大，橘黄→暗红 | 云底<-20℃、云顶<-38℃；红外云图难测顶温 |

**特殊云指示**：积云状云顶=对流不稳定（→降水→彩虹）；纤维状=产生降水（层状云底部出现纤维 → 云底降低，**不利火烧云**）；乳状云需云下 RH<50% 且温度直减率 ≥-6℃/km。

**伴随天象预报**：云隙光（低空气溶胶散射显形，反云隙光可达数百 km）；彩虹（最小偏转角 137.5°，彩虹锥 42° 顶角在太阳对侧，雨滴 >0.5mm，多在云幡/乳状云中）；日柱（片晶反射，太阳高度角 <20°，云底 -10~-25℃，最佳 -12~-18℃）；冰晕（环天顶弧 0-32°、环地平弧 58-90°、22°幻日 0-55° 为片晶；上/下切弧 0-35°、外接日晕 35-90°、22°日晕 0-90° 为柱晶；约半数冰晶云无晕）。

### 4.4 预报实操流程（教程第四章）

**短期预报（数值模式，≤36h）**：
1. 日落时间+太阳方位角 → 大气截面图（Tropical Tidbits/Windy/MeteoBlue），看日落方向沿线 RH 与 AOD 分布；
2. 识别云况（典型/非典型）；
3. 查本地探空：云底高度（RH>90% 视为有云）、云属、云厚；
4. 查 AOD：本地 + 光路上游（多取几个点）；
5. 套几何模型：等效云底高度（扣除等效地表高度）→ 验算能否出霞 → 算持续时间（火烧云三角 + 日落线速度）、高度角、开始时刻；
6. 判断伴随天象（云温/冰晶形态）；
7. **不确定性分析**（翻车因素）：
   - 云量风险：云内 RH 未饱和且云薄 → 云量不确定性被放大；
   - 云边界风险：湿度梯度缓 vs 陡、边界风速（沿日落方向分量 <15m/s 较小，15~30 有点大，>30 很大）、云边界与日落方向夹角 <10° 高度不确定；
   - 其他方向云量是否够、有无杂云挡光；
   - 气溶胶垂直分布未知（等效地表高度敏感性分析，0.5~4.0km 扫一遍）。

**两个完整案例**（深圳 2022-10-13 层积云晚霞；伊春 2022-10-14 卷层云晚霞）：流程、计算、不确定性、实况对照表格式齐全——复刻时值得全文抓取。

**临近预报（实况外推，1-2h）**：
- 红外云图测最高层云顶亮度温度 → 对照探空找对应云层（温差 <5℃ 算吻合；卷云因透明顶温严重偏高，须看纹理识别后查探空，取局部最低温）；
- 卫星云图定水平分布；卷云透光性判据：亮度温度接近地面温与云温均值 → 透光；
- 雷达图定降水分布；
- 外推云移动（层状云可靠，云洞/对流云不可靠）。
- **高云漏光/中云漏光/对流云火烧云 = 不支持基于模式的预报**，只能靠实况外推（云洞位置像随机噪声）。

## 5. 准确率体系（回测）

- 用 **ERA5 再分析**（上海 2022-06-24 ~ 2023-12-30，约 1.5 年）按当前算法回测，输出 **6 级混淆矩阵**：
  不烧 / 微烧 / 小烧 / 小到中烧 / 中到大烧 / 大烧。
- **双归一化**：按预报结果归一化（竖读：报 XXX 时实际概率分布）+ 按观测结果归一化（横读：实况 XXX 时预报分布）。
- **诚实声明**："实际的 GFS 预测表现只会比这个更差，这是上限，可以感受一下。"——承认 ERA5 回测是上限。
- 记录库支持按 云属/颜色/真实质量/天象 过滤查询（上海）。

## 8. 可复刻的自动化路线

1. 数据层：GFS/EC 云量多层（Open-Meteo 可代理）+ CAMS AOD → 逐小时格点；
2. 判云况：探空 RH 层/截面 → 云底高、云属（温度分层：>0℃ 水云、-20~0 混合、<-38℃ 必卷云）；
3. 几何层：日落线速度 + 火烧云三角 + 等效地表高度（AOD 敏感度扫描）→ 持续时间/开始时刻/高度角；
4. 评分层：鲜艳度多因子加权（云量相态含水量/面积/云底高/层间遮挡/AOD）→ 0-2.5 对数刻度；
5. 回测层：ERA5 每日回算 + 6 级混淆矩阵双归一化 + "上限"式诚实声明；
6. 实况层：卫星云图（FY-4B/向日葵）+ 雷达 + 用户反馈，做临近订正与标签积累。
